Support

Write to support@tilefold.app – the developer reads every message. If something went wrong, say which device and system version you have and what you were doing; a screenshot helps.

I bought Tilefold Plus, but it is locked

Open Settings › Tilefold Plus and tap Restore Purchases. Use the same Apple Account you bought it with. Plus is a one-time purchase and works on all your devices.

My records did not move to a new device

Records, game statistics and daily puzzle results are kept in your own iCloud. Make sure you are signed in to iCloud with the same account on both devices; the data arrives a little after the first launch.

The daily puzzle link opens the wrong thing

A link to tilefold.app/daily opens the daily puzzle in the game, or in the App Clip if the game is not installed. If it opens this site instead, update the game from the App Store.

Game Center

Game Center is optional. Scores and achievements are sent only while you are signed in; the game itself does not change without it.

Your data

How the game handles data is described in the privacy policy. To ask what was collected, or to have it deleted, write to privacy@tilefold.app.
